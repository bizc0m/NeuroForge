# GFXV1

## Neuro Forge Visual System

Version: 1.0  
Status: active  
Scope: logo, pages, app icons, prompts, public assets

## Core Identity

Name: Neuro Forge  
Positioning: A digital taillandier forging dedicated cognitive tools.  
Signature:

FORGED FOR ATYPICAL THINKERS.

THEN, GREAT RESULTS.

Principles: Explore. Understand. Connect. Invent.

## Palette

- Black: `#050505`
- White: `#f7f3ea`
- Alchemical red: `#b11226`

Use black as the dominant surface, white as structure, red as signal.

## Logo Direction

- pixel art monochrome;
- circular glyph;
- simplified brain;
- organic left side;
- digital circuit right side;
- controlled pixel dissolution;
- readable at 32 x 32 px;
- works without text;
- no hammer;
- no anvil;
- no artificial N or F;
- no gradient;
- no 3D;
- no decorative noise.

## Page Direction

- black background;
- white primary typography;
- red dividers, borders and active accents;
- centered primary text;
- high contrast;
- strict spacing;
- no soft decorative blobs;
- no generic tech gradient;
- no marketing filler.

## Typography

Use monospace or technical sans-serif.

Rules:

- uppercase for signatures;
- short lines;
- strong hierarchy;
- no negative letter spacing;
- no oversized text inside compact blocks.

## Asset Exports

Required logo sizes:

- 32 px
- 64 px
- 128 px
- 256 px
- 512 px
- 1024 px

Public assets must exist inside `docs/assets/logo/` for GitHub Pages.

Source assets must exist inside `brand/logo/source/`.

Repository exports must exist inside `brand/logo/exports/`.

## Prompt Template

```md
Create a Neuro Forge pixel art visual.

Style:
- black background
- white symbol
- alchemical red accents
- circular glyph
- simplified brain
- half organic, half circuit
- controlled pixel dissolution
- hard pixel edges
- high contrast
- readable at 32 x 32 px

Avoid:
- gradients
- 3D
- glow-heavy effects
- hammer
- anvil
- artificial N or F letters
- decorative clutter
- low contrast

Output:
- clean centered composition
- symbol usable without text
- export-ready square format
```

## Validation

Before publishing:

1. Check logo renders at 32 px.
2. Check public page loads the logo with HTTP 200.
3. Check black, white and red are present.
4. Check text is centered on the main page.
5. Check no required asset is outside the published root.
