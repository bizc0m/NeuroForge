## Rules

- `Taillandier ✓` requires Neuro Forge validation.
- `Blade` means the component conforms to the Nyx Blade interface/contract.
- `Core` is reserved for shared foundational components.
- `Standalone` means the application can operate independently.
- Use exactly one lifecycle badge: Stable, Experimental, Legacy or Archived.
- `macOS Native` requires a native macOS implementation; otherwise use the appropriate platform badge.
- `Local First` means primary user data remains local by design.
- `Offline Capable` means core functionality works without network access.
- `Privacy First` must only be used when privacy criteria are documented and validated.
- `Maintained` should preferably be generated dynamically from repository activity.
- README headers should normally show no more than 6–8 badges; this catalog is the source from which each project selects its relevant badges.
